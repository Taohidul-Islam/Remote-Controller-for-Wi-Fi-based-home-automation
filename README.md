9<h1>This is a Wi-Fi Based Remote Controller</h1>
<h2>The remote controller is specifically made for my previous project<a href="https://github.com/Taohidul-Islam/Wi-Fi-Based-Home-Automation"> Wi-Fi-Based-Home-Automation</a></h2>
<p>The remote controller has a thin form factor of 15mm. It uses a wesmos D1 mini as an MCU, a 3.7V Li-ion battery, TP4056 module(type-c) to charge the battery, and a TPS6123 module.<br>
It also does have a debug LED.</p>
<p>The keypad used in the remote is a membrane 4 by 4 matrix. Clicking specific button suck as numeric 1 to 8 gives specific http requests to a webserver hosted on the home automation. Then the server toggles respective switches from on to off or off to on. A, B, C, D and other keys are for extra functions such as display changer, reset buttons or led indicator toggler, firmware update requester for Home Automation etc. The remote controller is a accessory for the home automations device. </p>
<p>The remote can it's own update via OTA.
<h3>KeyMap</h3>
  <p>1---> Toggles Relay 1<br>
     2---> Toggles Relay 2<br>
     3---> Toggles Relay 3<br>
     4---> Toggles Relay 4<br>
     5---> Toggles Relay 5<br>
     6---> Toggles Relay 6<br>
     7---> Toggles Relay 7<br>
     8---> Toggles Relay 8<br>
     9---> Increase people count by one. <br>
     0---> Decrease people count by one. <br>
     A---> Changes display output and keeps the screen still<br>
     B---> Changes display output and keeps the screen switching<br>
     C---> Toggles LED indicator<br>
     D---> Toggles all relays at once.<br>
     *, 0, 9 simountaniously---> Resets Home Automation. <br>
     *, 0, 1 Simountaniously---> Request Home Automation to seek for updates. <br>
     #, 0, 1 Simountaniously---> Request the remote controller to seek for updates. <br>
     
  
  
  </p>
  
<p>The remote has a very compact form factor of about 7 by 7 by 2 cm. And it eradicates the direction problem we face with IR remotes.</p>
